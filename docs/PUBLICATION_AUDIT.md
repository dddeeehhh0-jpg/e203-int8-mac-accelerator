# Publication audit

Purpose: make it possible to publish this repository without accidentally
publishing someone else's code, a vendor library, contest material, or a
misleading number. Last reviewed: 2026-11-12.

## 1. Traffic-light classification

| Colour | Meaning | Disposition |
|---|---|---|
| Green | independently written RTL / TB / model / scripts / docs / figures | in the repository |
| Yellow | aggregated conclusions from the team contest project | author confirmed permission; only in `docs/case_study.md`, always labelled as a different project |
| Red | PDK, `.db/.lib/.lef`, SRAM macro, **vendor / contest netlist**, weights, audio, teammate source, contest documents, server paths/accounts | **never committed**; explicitly excluded by `.gitignore` |

A clarification that matters after the synthesis work: `syn/run_synth.py`
generates **generic-cell** netlists into `syn/out/`. These are self-generated
build products from this repository's own RTL, contain no vendor library and
no contest data, are **gitignored**, and appear only as CI artifacts. They are
not the "Red" netlists above.

## 3. Third-party attribution

Only three upstream projects are linked (in `README.md`) as examples of
repository organisation. Their code, figures and README text were not copied.
The upstream E203 project is Apache-2.0; this repository does not vendor it and
does not redistribute any part of it.

Toolchain packages (`pyverilog`, `yowasp-yosys`, `iverilog`, `Pillow`) are
declared as dependencies and installed by CI at run time; none of their source
is included in the tree. `syn/generic_cells.v` was written from scratch against
the documented generic-cell port list, not copied from Yosys' `simcells.v`.

## 4. Data boundary

The repository contains **no** audio, no Speech Commands data, no trained
weights, no `.db/.lib/.lef`, no SRAM macro, no vendor or contest netlist, no DC
report and no contest screenshot. All stimuli are synthetic integers generated
from `SEED = 20261112`. `.gitignore` hard-excludes the corresponding patterns.
The only netlists that exist are the **generic** ones generated from this
repository's own RTL into the gitignored `syn/out/`; they are CI artifacts,
never committed files.

## 6. Desensitisation record

- Absolute server paths, user names, host names and account identifiers: never
  present in any committed file (checked by grep before publishing).
- No screenshot from the contest environment is embedded in any document.
- `case_study.md` deliberately omits the organiser's document text, the
  submission archive layout, and teammate names.
- `.gitignore` blocks `server_*/`, `*_screenshot*`, `pdk/`, `weights/`,
  `dataset/`, audio and archive patterns as a second line of defence.

## 7. Claims that are prohibited

1. Do not present contest source (or a renamed copy of it) as this repository's
   own code.
2. Do not write "full-chip verification passed" - only module-level continuous
   inference and SoC-level sampling.
3. Do not write "0.462 mW is the chip power" - it is accelerator-local.
4. Do not write "passed the organiser's evaluation" - the 600-sample set was
   team-selected.
5. Do not quote a coverage percentage or a PPA result for this repository.
